# Cognitive Kernel Module

Low-Level Cognitive Processing Components

This module contains low-level cognitive processing components that handle fundamental cognitive functions like attention, context management, and scheduling.

## Components

- **Kernel** (`kernel.py`) - Core cognitive kernel that orchestrates cognitive cycles
- **Scheduler** (`scheduler.py`) - Manages timing and execution of cognitive processes
- **Context Manager** (`context_manager.py`) - Manages working memory and context
- **Attention Manager** (`attention_manager.py`) - Controls focus and attention allocation
- **Cognitive Bus** (`cognitive_bus.py`) - Facilitates communication between cognitive components (shared with cognition module)

## Purpose

These components provide the foundational cognitive operations that support higher-level metacognitive functions in the cognition module. They handle the basic "thinking" processes rather than "thinking about thinking".
