# Cognition Module

High-Level Metacognitive Components

This module contains high-level metacognitive and self-improvement components that enable the system to think about its own thinking, learn from experience, and improve over time.

## Components

- **Learning Velocity** (`learning_velocity.py`) - Tracks and optimizes learning speed and efficiency
- **Meta Learning Engine** (`meta_learning_engine.py`) - Learns how to learn better
- **Failure Analyzer** (`failure_analyzer.py`) - Analyzes failures to improve future performance
- **Self Improvement** (`self_improvement.py`) - Coordinates self-improvement initiatives
- **Skill Discovery** (`skill_discovery.py`) - Discovers new skills and capabilities
- **Strategy Synthesizer** (`strategy_synthesizer.py`) - Combines insights into coherent strategies
- **Intelligence Reporter** (`intelligence_reporter.py`) - Reports on cognitive metrics and insights
- **Performance Tracker** (`performance_tracker.py`) - Tracks performance metrics over time
- **Decision Tracker** (`decision_tracker.py`) - Tracks decisions and outcomes
- **Delegation Protocol** (`delegation_protocol.py`) - Manages delegation of tasks to sub-agents
- **Hierarchical Agent Registry** (`hierarchical_agent_registry.py`) - Manages agent hierarchies
- **Swarm** (`swarm.py`) - Coordinates swarm intelligence behaviors
- **Cognitive Bus** (`cognitive_bus.py`) - Facilitates communication between cognitive components (shared with cognitive_kernel module)

## Purpose

These components provide the metacognitive capabilities that enable the system to improve its own performance, learn from experience, and adapt to new situations. They operate at a higher level of abstraction than the cognitive kernel components.
